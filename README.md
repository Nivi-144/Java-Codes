## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/Nivi-144/Java-Codes.git
```

2. Open the project in your favorite IDE (IntelliJ IDEA, Eclipse, VS Code, etc.)

3. Compile and run any Java file

```bash
javac FileName.java
java FileName
```
